# Design notes: `become-a-tutor.html`

Moved out of the page source so they are not visible in view-source on the
live site. These are the decisions for this page: what was deliberately left
out and why, what must not change, and which instructions conflicted.

**Read this before editing the page.**

## Block 1

```
============================================================
  NOTE FOR CLAUDE CODE, tutor recruitment
  ============================================================
  NOTHING ON THIS PAGE STATES A PAY RATE. No hourly figure has been
  agreed for publication, so rates are discussed at interview. Do
  not add a number, and do not imply the parent-facing £28-35 is
  what a tutor receives; it is not.

  There is no application form. Applications come by email, which
  keeps CVs out of a static site with no server. If an application
  form is ever wanted it belongs on the portal, not here.

  This page has no active nav link: it is reachable from the
  footer and the mobile menu, not the desktop nav.

  Do not reinstate: the free written assessment, the 15-minute
  consultation, or the gold accent.
  ============================================================
```
